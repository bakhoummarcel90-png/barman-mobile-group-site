# Branche media — fichiers vidéo uniquement

Cette branche stocke les vidéos destinées aux réseaux sociaux (liens publics pour Metricool).
Elle ne contient pas le code du site.

NE PAS SUPPRIMER vercel.json : il empêche Vercel de tenter de déployer cette branche
(sinon un e-mail « Le déploiement de prévisualisation a échoué » est envoyé à chaque ajout de vidéo).

Pour ajouter une vidéo : ajouter le fichier dans videos/ sans retirer les autres fichiers.
